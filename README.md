# Uber Ride Booking Analysis – Exploratory Data Analysis

## 📌 Project Overview

This project presents an **Exploratory Data Analysis (EDA)** of an Uber ride booking dataset containing **150,000 booking records and 21 features**.

The objective of this project is to analyze booking patterns, identify factors affecting ride completion and cancellation, and extract meaningful business insights from the data.

## 📊 Dataset

* **Records:** 150,000
* **Features:** 21
* **Domain:** Ride Booking / Transportation
* **Data Type:** Structured booking data

The dataset contains information about booking status, vehicle type, pickup and drop locations, booking value, ride distance, payment method, driver and customer ratings, and cancellation details.

## 💡 Key Insights

* **62%** of bookings were completed successfully.
* **18%** of bookings were cancelled by drivers.
* **18:00 (6 PM)** was the peak booking hour.
* **Monday** recorded the highest number of bookings among the days of the week.
* **July** had the highest number of bookings among the months analyzed.
* **UPI** was the most commonly used payment method.
* Driver and customer ratings were generally high, with average ratings of approximately **4.23 and 4.40** respectively.
* Common customer cancellation reasons included **wrong address, change of plans, and driver-related issues**.
